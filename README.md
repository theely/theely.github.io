# 8B to 700B

One RL training loop, run four ways on [Alps](https://www.cscs.ch/computers/alps) — from an
8B model on grade-school maths to a 700B-class mixture-of-experts on competition maths — and
the memory wall, framework gap, or reward bug that had to be solved at each step.

Published at **https://theely.github.io/8b-to-700b/**

The article is a single self-contained `index.html`: inline CSS and SVG, no build step, no
JavaScript. The only external dependency is Google Fonts.

The engineering log it draws on lives in
[eth-cscs/alps-extended-images](https://github.com/eth-cscs/alps-extended-images).
